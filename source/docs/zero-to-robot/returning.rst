.. rubric:: FRC: What to Update
   :class: wl-frc-text

1. **Update your tools.** Install the Driver Station and, for desktop
   development, WPILib for the season.
2. **Update Systemcore.** Follow the
   :doc:`imaging instructions <step-3/imaging-your-systemcore>` for your
   controller hardware revision.
3. **Migrate your project.** Import last year's project and re-add vendor
   libraries for the current release.
4. **Review removed tools and features.** Check
   :doc:`Removed in 2027 </docs/yearly-overview/removed-features>` before testing.

Use the :doc:`full returning-team checklist
</docs/yearly-overview/returning-quickstart>` for the detailed update steps.

.. rubric:: FTC: What to Update
   :class: wl-ftc-text

Moving from the FTC SDK to Systemcore and Motioncore? Your FTC SDK project
cannot be imported as a WPILib project.

1. **Learn the WPILib program structure.** Start with
   :doc:`New to WPILib <new-to-wpilib>` for subsystems, commands, and hardware
   classes.
2. **Create a WPILib project.** Choose your language and environment in
   :doc:`Robot to Motion <introduction>`.
3. **Configure your hardware in the new project.** Set up the motors and
   sensors for your Systemcore and Motioncore control system.
